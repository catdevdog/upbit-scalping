## 2. 설치 및 설정



## 3. ML 모델 학습

### Step 1: 캔들 데이터 수집

```bash
node scripts/backfill-candles.js --days=7
```

- 최소 **5,000개** 캔들 필요 (약 3.5일)
- 권장: 7일 이상

### Step 2: 모델 학습

```bash
node scripts/train-ml-model.js
```

- `logs/ml_model.json` 생성
- 검증 정확도 확인

### Step 3: (선택) Walk-forward 검증

```bash
node scripts/walkforward-validate.js
```

- 시간순 폴드별 성능 확인
- 과적합 여부 검증

### 자동 재학습

- 기본: **24시간마다** 자동 재학습
- 설정: `ML_AUTO_RETRAIN=true`

```
╔══════════════════════════════════════════════════════════════╗
║ ⚡ 업비트 ML Bot 4.1                                          ║
║ 2026. 1. 17. 오전 2:43:11  KRW-BTC  [PAPER]                  ║
╚══════════════════════════════════════════════════════════════╝

💳 계좌  KRW: 5,000,000  |  총자산: 5,000,000

○ 조건 미충족  140,299,000 KRW

📊 핵심 지표
┌─────────────────────────────────────────────────────────────┐
│ 추세 ✗ EMA 140309222/140452052 | VWAP 140118475 ↑          │
│ 변동성 ✗ ATR 0.059%                                         │
│ 거래량 ✗ RVOL 0.30x                                         │
│ 오더북 ✗ Imb 14% | Spr 96틱                                 │
└─────────────────────────────────────────────────────────────┘

🎲 확률  예측확률(p)=1.6%  임계확률(p*)=58.0%  차이(Δ) -56.4%

🚫 진입 차단: 오더북 조건 미달
```

### 지표 설명

| 지표     | 의미                | 좋은 상태       |
| -------- | ------------------- | --------------- |
| **EMA**  | 지수이동평균 (추세) | Fast > Slow (✓) |
| **VWAP** | 거래량가중평균가    | 가격 > VWAP (↑) |
| **ATR**  | 변동성 (%)          | 0.038% 이상     |
| **RVOL** | 상대거래량          | 1.5x 이상       |
| **Imb**  | 매수호가 불균형     | 28% 이상        |
| **Spr**  | 스프레드 (틱)       | 2틱 이하        |

### 확률 (p, p\*)

| 값      | 의미                       |
| ------- | -------------------------- |
| **p**   | ML 모델이 예측한 승률      |
| **p\*** | 손익분기 승률 (진입 기준)  |
| **Δ**   | p - p\* (양수면 진입 가능) |

## 6. 핵심 개념 이해하기

### ML 확률 (p) 계산

```
p = 1 / (1 + e^(-z))

z = bias + Σ(weight × feature)

features = [ATR, RVOL, RSI, EMA비율, 오더북 등]
```

### 손익분기 확률 (p\*) 계산

```
p* = SL / (TP + SL)

예) TP=0.8%, SL=0.5%
   p* = 0.5 / 1.3 = 38.5%
```

→ 승률이 38.5% 이상이면 기대값이 양수(+)

### 횡보장 vs 모멘텀

```
횡보장: p = 1~5% (진입 안 함)
       - 거래량 적음, EMA 역전, 스프레드 넓음

모멘텀: p = 60~90% (진입!)
       - 거래량 폭발, EMA 정배열, 오더북 매수 우위
```

### 청산 로직

```
1. SL (-0.5%)     → 손절
2. TP (+0.8%)     → 익절
3. BE (+0.3% 후)  → 손절선을 +0.1%로 이동
4. TRAIL         → 고점 대비 -0.2% 이탈 시
5. STALL (10분)  → BE 미도달 시 정리
6. TIMEOUT (30분) → 강제 정리
```

## 7. 자주 묻는 질문

### Q: p가 항상 1~5%로 낮아요

**A**: 정상입니다. 횡보장에서는 낮고, 모멘텀 발생 시 급상승합니다.

### Q: "ML 모델 없음" 에러

**A**: 모델 학습 필요

```bash
node scripts/train-ml-model.js
```

### Q: "데이터 부족" 에러

**A**: 캔들 백필 필요

```bash
node scripts/backfill-candles.js --days=14
```

### Q: 진입이 너무 안 돼요

**A**: 조건이 엄격할 수 있습니다. `.env`에서 조정:

```env
ML_MIN_PROB=0.55        # p* 기준 낮추기
MIN_IMB=0.20            # 오더북 기준 완화
MAX_SPREAD_TICKS=3      # 스프레드 허용 늘리기
```

### Q: 너무 자주 진입해요

**A**: 조건을 강화하세요:

```env
ML_MIN_PROB=0.65
MIN_ENTRY_GAP_MINUTES=15
```

### Q: 실거래 전환 방법

**A**:

1. `.env`에서 `PAPER=false`
2. API 키 입력
3. 충분한 KRW 잔고 확인
4. `npm start`

## 📞 문제 해결

| 에러           | 해결책                            |
| -------------- | --------------------------------- |
| HTTP 429       | API 과다 호출. 잠시 대기          |
| 401/422        | API 키 권한 확인, IP 화이트리스트 |
| WebSocket 끊김 | 자동 재연결됨, 네트워크 확인      |
| 터미널 깜빡임  | `USE_ALT_SCREEN=true` 설정        |
